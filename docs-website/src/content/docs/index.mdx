## Features

<CardGrid stagger>
	<Card title="3D Comparison" icon="eye" link="/user-guide/first-steps">
		Visualize added, removed, and shared geometry in distinguished colors.
	</Card>
	<Card title="Tree Comparison" icon="tree" link="/user-guide/first-steps">
		Catch unintended side-effects before manufacturing. Every property change surfaced.
	</Card>
	<Card title="Review Workflow" icon="clipboard" link="/user-guide/first-steps">
		Review changes incrementally, mark documents as reviewed, and save
		the result as a new iteration when ready.
	</Card>
	<Card title="Multi-Document Support" icon="documents" link="/user-guide/concepts">
		Review and iterate on multiple related documents at once, such as
		assemblies spread across several .FCStd files.
	</Card>
	<Card title="Safe Restore" icon="undo" link="/user-guide/first-steps">
		Restore individual files or batches from any saved iteration back
		onto disk without rewriting project history.
	</Card>
	<Card title="Install" icon="download" link="/user-guide/installation">
		Get History Workbench running in your FreeCAD installation.
	</Card>
